# Executive Summary
This project implements an end-to-end predictive maintenance solution for ~59,400 rural water points in Tanzania using 40 raw features from DrivenData. Through targeted feature engineering—including geographic imputation, categorical consolidation, and date extraction—and hyperparameter optimization via Grid Search CV, the Random Forest classification accuracy improved from a 72% baseline to 78%. The final model outputs 3-class status predictions (functional, functional needs repair, non functional) directly to prediction.csv, landing within 5 percentage points of the top public leaderboard benchmark (83%).
